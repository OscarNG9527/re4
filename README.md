# 大湾区音雄争霸 🎸
一款**大湾区乐队主题**的回合制网页游戏，参考《崩坏：星穹铁道》经典玩法！

## 游戏特色
✅ 大湾区本土乐队阵营（深圳/珠海/广州/香港/澳门）
✅ 星穹铁道同款回合制机制（普攻/战技/终结技/技能点/能量系统）
✅ 纯前端开发，打开浏览器即玩
✅ 支持GitHub Pages在线部署

## 登场乐队
- **我方阵营**：深圳 - 夜一乐队（流行摇滚）
- **敌方阵营**：珠海 - Vivid Melody（清新流行）

## 核心玩法（参考星穹铁道）
1. **普攻**：基础伤害，积攒能量
2. **战技**：消耗技能点，高额群体伤害
3. **终结技**：能量满100释放，秒杀级伤害
4. **技能点**：每回合恢复1点，上限3点
5. **回合制**：我方行动 → 敌方行动

## 快速开始
### 本地游玩
1. 克隆本项目
2. 直接打开 `index.html` 文件
3. 开始对战！

### 在线游玩（GitHub Pages）
1. 上传项目到你的GitHub仓库
2. 进入仓库 → Settings → Pages
3. Source选择 `main` 分支 → 保存
4. 自动生成在线游玩链接

## 扩展修改
你可以轻松添加更多大湾区乐队：
- 广州拾音社
- 香港Supper Moment
- 澳门BLUE ZONE
- 佛山/东莞本土乐队

修改 `gameData` 中的角色数据即可新增角色！
